# 📚 Ampliación de Fundamentos del Hardware - 2º ASIR

Repositorio con los trabajos y proyectos realizados en la asignatura **Ampliación de Fundamentos del Hardware** del ciclo formativo de **2º de Administración de Sistemas Informáticos en Red (ASIR)** durante el curso académico **2025-2026**.

🌐 https://sedanodev.github.io/2asirAFH2526/trabajos/ 
---

## 📋 Contenido de la Asignatura

Esta asignatura profundiza en los conceptos fundamentales del hardware informático, cubriendo:

- **Arquitectura del Hardware**: Componentes del PC y servidores
- **Monitoreo y Mantenimiento**: Procedimientos de instalación, desinstalación y mantenimiento
- **Optimización de Sistemas**: Mejora del rendimiento del hardware
- **Inteligencia Artificial**: Aplicaciones de IA en sistemas modernos
- **Compresión de Datos**: Técnicas de cuantización y optimización de datos

---

## 🎯 Proyectos Realizados

### 1. **Agente IA**
Exploración de sistemas basados en inteligencia artificial y su implementación en entornos de administración de sistemas.
- 📄 Documento: `trabajos/AgenteIA.html`

### 2. **Cuantización**
Estudio de técnicas de cuantización y compresión de datos para optimizar el almacenamiento y transmisión de información.
- 📄 Documento: `trabajos/cuantizacion.html`

### 3. **Modelos de Hardware**
Análisis de diferentes arquitecturas y modelos de componentes hardware, sus características y aplicaciones.
- 📄 Documento: `trabajos/modelos.html`

### 4. **Desmontar y Montar un PC**
Procedimientos prácticos para el desarmado, mantenimiento y reensamblado de equipos informáticos de escritorio.
- 📄 Documento: `trabajos/Desmontar y Montar un PC - Luis Sedano.pdf`

### 5. **Desmontar y Montar un Servidor**
Procesos específicos para trabajar con servidores, incluyendo consideraciones de seguridad y continuidad operativa.
- 📄 Documento: `trabajos/Desmontar y Montar un Servidor - Luis Sedano.pdf`

### 6. **Crear una Web Estática en Github**
Proyecto de desarrollo web implementando un portafolio responsivo con HTML, CSS y GitHub Pages.
- 📄 Documento: `trabajos/Crear una web estática en Github - Luis Sedano.pdf`
- 🌐 Resultado: `trabajos/index.html` (Portafolio web interactivo)
